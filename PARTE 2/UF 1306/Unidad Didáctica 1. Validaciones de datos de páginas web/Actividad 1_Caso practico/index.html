Unidad Didáctica 1. Validaciones de datos de páginas web

PREGUNTAS/ACTIVIDADES A REALIZAR

Pregunta 1 Explique cuál es la diferencia entre validar y verificar. ¿Cuál es el proceso que se sigue para validar y para verificar una web? Ponga un ejemplo para un caso de validación y otro para un caso de verificación.

    Pregunta 2 Cree una página web con un formulario.

  • a. El formulario tendrá campos de: nombre, edad, email, sexo (con 2 opciones “Masculino” y “Femenino”) y un área de texto para un mensaje. Además tendrá un botón para enviar y otro para borrar los datos del formulario..
  • b. Crear un archivo JavaScript con una función “validarFormulario” que se ejecute al pulsar el botón de “Enviar”..
  • c. Validar con JavaScript que el campo “nombre” no esté vacío. Si está vacío se mostrará el mensaje “El campo ‘nombre’ es obligatorio” y se pondrá el foco en el campo “nombre”. Si hay un nombre entonces se mostrará el mensaje “Formulario enviado”..
  • d. Validar con JavaScript que el campo “nombre” sólo acepte caracteres de letras y espacios en blanco. Si no es válido mostrará el mensaje “El campo nombre sólo acepta letras y espacios en blanco”, pondrá el foco en el campo y no enviará el formulario.
  • e. Validar con JavaScript que el campo edad no está vacío y que contiene números entre 0 y 120. Avisar con mensajes en caso de datos no válidos y poner el foco en el campo.
  • f. Validar el campo email para que no esté vacío y sea un email válido.
  • g. Validar el campo mensaje para que no pueda contener más de 255 caracteres.
