Unidad Didáctica 1. Validaciones de datos de páginas web

PREGUNTAS/ACTIVIDADES A REALIZAR

Pregunta 1 Cree una página html con un formulario. El formulario tendrá campos de: nombre, edad, email, sexo (con 2 opciones “M” y “F”) y un área de texto para un mensaje. Además tendrá un botón para enviar y otro para borrar los datos del formulario. Se usará jQueryValidate para la validación y será necesario incluir mensajes personalizados de los errores.

  • a. Se realizarán las validaciones con jQuery y su pluginValidate. Descargar de internet y enlazar los archivos necesarios en el documento html.
  • b. Validar el campo nombre para que no esté vacío y sólo acepte letras y espacios en blanco.
  • c. Validar la edad para que sea obligatoria sólo acepte números entre 18 y 120.
  • d. Validar el email para que no esté vacío y sea un email correctamente escrito.
  • e. Validar el campo sexo para que sea obligatorio realizar una selección.
  • f. Validar el campo mensaje para que no tenga más de 255 caracteres.

    • Pregunta 2 Realizar una verificación de los datos del formulario.Se pedirá el email y un password. Se pedirá que el password se escriba 2 veces y que coincidan para evitar errores.

  • a. Crea el archivo html con el formulario de registro.
  • b. Validar el email, que no esté vacío y que sea un formato de email correcto.
  • c. Validar el password para que tenga una longitud de entre 6 y 10 caracteres.
  • d. Validar con JavaScript que el campo “nombre” sólo acepte caracteres de letras y espacios en blanco. Si no es válido mostrará el mensaje “El campo nombre sólo acepta letras y espacios en blanco”, pondrá el foco en el campo y no enviará el formulario.
