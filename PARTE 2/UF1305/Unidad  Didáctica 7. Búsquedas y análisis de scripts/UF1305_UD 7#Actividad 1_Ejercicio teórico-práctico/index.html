Programación con lenguajes de guión en páginas web (UF1305)

Unidad Didáctica 7. Búsqueda y análisis de scripts

PREGUNTAS / ACTIVIDADES

Pregunta 1. ¿Cuáles son los distintos tipos de buscadores que podemos encontrar en internet atendiendo a la manera de buscar la información? Explique lo que son y lo que hacen cada uno de ellos.

Pregunta 2. Creación de una página web donde insertaremos un script encontrado en internet.

  • a. Buscar scripts en internet
  • b. Insertar reloj
  • c. Crear HTML con reloj
  • d. Efecto nieve

Pregunta 3. Búsquedas con expresiones regulares.

  • a. Buscar una expresión para verificar un código postal. Ejemplo: 29840
  • b. Buscar una expresión para que la fecha tenga formato DD/MM/AAAA. Ejemplo: 20/01/2016
  • c. Buscar una expresión para validar un email. Ejemplo: nombre@gmail.com
  • d. Buscar una expresión para validar un número de teléfono nacional. Ejemplo 95255115
