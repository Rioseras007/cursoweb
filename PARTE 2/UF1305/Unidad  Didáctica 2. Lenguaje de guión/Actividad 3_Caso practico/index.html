Programación con lenguajes de guión en páginas web (UF1305)

Unidad Didáctica 2. Lenguaje de guión

PREGUNTAS/ACTIVIDADES A REALIZAR

Pregunta 1. Cree un nuevo documento html.

  • a. ¿Qué función será necesaria para mostrar información de la fecha o la hora actual en una página web mediante JavaScript? Describa el funcionamiento de esa función. ¿Qué parámetros utilizará?

  • b. ¿Qué método habrá que utilizar para mostrar la hora? Que se muestre en la página web la hora a la que la página se ha cargado de forma que se muestren las horas y minutos. Por ejemplo, "La página web se ha cargado a las 13 horas y 5 minutos". Realice una captura de pantalla.

  • c. ¿Qué método se utiliza para escribir directamente en la página web desde JavaScript? ¿Qué parámetros hay que pasarle a ese método?

  • d. Cree una función llamada "escribirDespedida()" que muestre el texto "Hasta la próxima visitante", en la página web. ¿Es necesario pasarle algún parámetro a la función?

  • e. Introduzca un botón en la página web con el texto "Salir". Al pulsarlo se ejecutará la función. Realice una captura de pantalla.

  • f. Cree una función llamada "mostrarHoraActual()" que muestre la hora actual en una ventana emergente de la forma "Son las 5 horas y 20 minutos".

  • g. Introduzca un botón en la página web con el texto "¿Qué hora es?". Al pulsarlo debe ejecutarse la función "mostrarHoraActual()".
