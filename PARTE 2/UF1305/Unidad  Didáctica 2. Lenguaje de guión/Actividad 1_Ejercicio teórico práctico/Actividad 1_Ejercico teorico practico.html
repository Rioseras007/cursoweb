Integración de componentes software en páginas web (MF0951_2)

Programación con lenguajes de guión en páginas web (UF1305)

Unidad Didáctica 2. Lenguaje de guión

PREGUNTAS/ACTIVIDADES A REALIZAR

Pregunta 1. Responde brevemente a las siguientes preguntas:

  • a. Explica qué es un lenguaje interpretado.
  • b. Explica qué es un lenguaje compilado.
  • c. ¿Qué es un disparador de eventos y cómo funciona?
  • d. ¿Qué es la sintaxis del lenguaje del guión?

Pregunta 2. Busca en internet librerías de JavaScript para añadir más funcionalidad a una página web. Encuentra al menos 3, indicando su nombre y para qué sirven. ¿Cómo se podría hacer uso de estas librerías y las funcionalidades que ofrecen en una página web?

Pregunta 3. Elabora un cuadro resumen donde se enumeren y clasifiquen los distintos tipos de eventos en JavaScript según sean de ratón, de teclado o de otro tipo, indicando el momento en que se producen.

Cuadro Resumen de Eventos en JavaScript

Tipo de evento Evento ¿Cuándo se produce?
Ratón click Cuando el usuario hace clic sobre un elemento.
Ratón dblclick Cuando se hace doble clic sobre un elemento.
Ratón mousedown Cuando se presiona un botón del ratón.
Ratón mouseup Cuando se suelta un botón del ratón.
Ratón mousemove Cuando el puntero se mueve sobre un elemento.
Ratón mouseover Cuando el puntero entra en un elemento.
Ratón mouseout Cuando el puntero sale de un elemento.
Teclado keydown Cuando se presiona una tecla.
Teclado keyup Cuando se libera una tecla.
Teclado keypress Cuando se pulsa una tecla de carácter.
Formulario focus Cuando un elemento recibe el foco.
Formulario blur Cuando un elemento pierde el foco.
Formulario change Cuando cambia el valor de un campo.
Ventana load Cuando la página termina de cargarse.
Ventana resize Cuando cambia el tamaño de la ventana.
Ventana scroll Cuando el usuario desplaza la página.
