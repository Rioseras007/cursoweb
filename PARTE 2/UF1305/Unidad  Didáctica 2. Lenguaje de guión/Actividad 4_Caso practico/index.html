Programación con lenguajes de guión en páginas web (UF1305)

Unidad Didáctica 2. Lenguaje de guión

PREGUNTAS/ACTIVIDADES A REALIZAR

Pregunta 1. Elabora una página web donde se incluya código JavaScript que pedirá datos de entrada al usuario y devolverá una salida con el resultado de los datos procesados.

  • a.Realice una descripción de lo que son scripts inmediatos, diferidos e híbridos.

  • b. Al cargar la página se mostrará un mensaje de alerta mostrando un mensaje de bienvenida, “Bienvenido a la página que realiza sumas”..

  • c. Se crearán 2 botones. Uno para introducir el primer número y otro para el segundo. Al pulsar cualquiera de los 2 botones se pedirá al usuario que introduzca un número para realizar la suma.

  • d.Se pondrá otro botón para mostrar el resultado de la suma. Al pulsar este botón se calculará la suma de los datos introducidos y se mostrará el resultado por pantalla.

  • e. Describe las funcionalidades adicionales implementadas en la calculadora más allá de la suma.
