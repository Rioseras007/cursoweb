Programación con lenguajes de guión en páginas web (UF1305)

Unidad Didáctica 6. Los eventos del lenguaje de guión

PREGUNTAS/ACTIVIDADES A REALIZAR

Pregunta 1 Implementar un contador en una página web.

  • a. Poner un botón con el texto “Incrementar contador”.Cada vez que se pulse el botón se mostrará una ventana emergente con el valor del contador.
  • b.Modificar el programa para que aparezcajunto al botón una etiqueta en la página web que muestre el valor del contador. Cada vez que se pulse el botón se incrementará el valor de ese contador y se mostrará su valor en la propia página web.
    • Pregunta 2 Creación de una aplicación que cambia de color de fondo de la página al pasar el ratón por encima de ciertas etiquetas.

  • a. Inserte 3 etiquetas
  • b. Cree una función JavaScript que se le pase como parámetro un color y coloree el fondo de la página de ese color.
  • c. Asigne eventos a cada una de las etiquetas para que al pasar el ratón sobre ellas se coloree el fondo de la página de ese color
  • d. Asigne también a las etiquetas eventos para que al salir el ratón de ellas se vuelva a poner el fondo de la página de color blanco.

    • Banda sonora gentileza de Suno
