Unidad Didáctica 6. Los eventos del lenguaje de guión

PREGUNTAS/ACTIVIDADES A REALIZAR

Pregunta 1 Creación de una aplicación que cambia el color de una caja al pinchar sobre ella con el ratón.

  • a. Incluya en la página un div de 300x300 píxeles con color de fondo verde.
  • b. Cree una función que ponga el color de fondo del div en color rojo y otra función que ponga el color de fondo del div en color verde.que muestre el valor del contador. Cada vez que se pulse el botón se incrementará el valor de ese contador y se mostrará su valor en la propia página web.

    • Pregunta 2 Creación de una página web y asignación de eventos. Cree una página web con un formulario donde se pida el nombre, la edad, y el sexo, utilizando un selector que permita elegir entre hombre y mujer. Añada los eventos que se piden.

  • a. ¿Qué evento utilizaría si se quiere que aparezca un mensaje de alerta indicando “página cargada” en el momento que se cargue la página web? Añada el evento a la página web.
  • b. ¿Qué evento utilizaría si se quiere que al tener el foco en el campo de texto para el nombre se resalte su etiqueta correspondiente de “nombre”?. Introduzca los cambios en la página web.
  • c. Ahora se quiere que al quitar el foco del campo de texto nombre se vuelva a dejar la etiqueta como estaba. ¿Qué evento se debe utilizar? Realice los cambios en la página web.
  • d. ¿Qué evento se utilizaría si se desea que en el momento de cambiar el valor de “sexo” cambien los colores de las letras? si se selecciona “hombre” se pongan las letras de color azul y si se selecciona “mujer” se pondrán de color rosa.
  • e. ¿Qué evento se usaría si se desea que al pulsar la tecla “w” se abra la página de google en el navegador? Introduzca este evento en la página web.
