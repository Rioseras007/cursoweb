La etiqueta "head" sirve para contener toda la información interna y no visible directamente de una página web, pero que es esencial para que el navegador y los buscadores entiendan cómo debe funcionar y mostrarse.

Incluye obligatoria la etiqueta "title" que muestra el titulo de la pagina Incluye la etiqueta meta que puede incluir informacion del tipo de codificacion ,autor,etc. Tambien puede contoner la etiqueta link entre otras.

La etiqueta "p" sirve para definir los distintos parrafos en los documentos pudiendo dar estilos diferentes a cada parafo si asi lo necesitamos

Los dos editores externos al sistema opertativo Windows que he instalado y utilizados han sido Notepad ++ y Sublimetext.
