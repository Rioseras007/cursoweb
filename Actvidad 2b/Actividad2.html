Atributos más importantes de la etiqueta IMG:

src      → Ruta de la imagen
alt      → Texto alternativo (accesibilidad y SEO)
width    → Ancho
height   → Alto
title    → Texto emergente al pasar el ratón
loading  → Carga diferida (lazy)
srcset   → Imágenes adaptativas
sizes    → Tamaños para responsive
